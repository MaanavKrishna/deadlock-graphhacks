# Browser acceptance checks

Before the UI exists, `/` has no application document. After implementation verify:

- Desktop: network is legible; Discover exchanges returns real graph paths; selection highlights the path; Negotiate opens persisted representative decisions and terms.
- Approvals: each member requires a separate explicit approval; final member commits the full cycle; export contains terms and events.
- Recovery: withdraw Motionhaus from an awaiting agreement; all holds release; its status is invalidated; a new discovery offers a path without Motionhaus.
- Directory: edit hours/deadline; invalid input displays an error; create a new profile.
- Memory: refresh preserves agreement and events; history reopens an older agreement.
- Mobile at 390px: no horizontal document overflow; every primary control is reachable and labeled.
- Keyboard focus is visible; modal supports Escape and focus restoration; reduced motion disables optional effects.
- No browser errors or failed application requests during the valid journey.
