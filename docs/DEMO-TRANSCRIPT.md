# Live walkthrough transcript

Actual browser interactions with live Claude Haiku 5.5. Narration uses a local synthetic voice.

## The deal between the deals

A designer needs a writer. The writer needs video. The video editor needs design. No pair can swap directly. Deadlock uses FalkorDB to find the connected agreement. This is the running application, using real Claude Haiku five point five representatives and authored sample agencies. The models make bounded decisions. Hard constraints are enforced by code, and humans retain final approval. Every proposed exchange, tool decision and capacity hold persists in the graph.

## Real model decisions, recorded

The first live negotiation proposed ten hours per participant. Each Claude representative called inspect exchange, read the graph context, and accepted. Studio North then provided explicit feedback: prefer receiving at most eight hours next time. That preference became a source-backed lesson in FalkorDB. In the next live run, Studio North countered the terms. Earlier acceptances were cleared, and every representative had to accept the revised proposal again.

## Memory that changes behavior

The Memory view shows the actual recorded outcomes: ten hours with learned preferences disabled, and eight hours enabled. The agency profiles, capacity, execution mode and provider-reported model identity match. Both agreements and the original feedback are linked. This is one observed model outcome, not a guarantee of identical future choices. Independent integration tests also verify the policy comparison across a database restart, and confirm that disabling memory restores the original terms.

## The graph responds when plans change

Now pause a participant before human approval. The pending agreement becomes invalid and its capacity holds are released. A fresh traversal discovers another path through Frame Lab. This recording also captures a real model failure: a representative repeats the current proposal. The coordinator rejects the loop and reserves no new capacity. Failed model choices are retained in the evidence, rather than disguised as successful negotiations. The existing history and source-backed preference remain available.

## A harder four-party challenge

In a separate challenge workspace, ten agencies have unequal valuations and different deadlines. Premiere's high-credit offer is blocked because nine-day delivery misses the recipient's deadline. Instead, the graph finds a feasible four-party path through Orbit Films, Shipyard, Signal Press and Studio North. Claude representatives evaluate real terms with unequal hours. Approval remains individual. The final human approval commits all four outgoing capacity amounts together in one graph transaction.

## A workspace for your own network

Deadlock also supports an empty working workspace. Add your own agency offers, needs, capacity, valuations and delivery deadlines. These are user-entered profiles rather than a hardcoded list of exchange participants. The same graph traversal and live agent tools handle their negotiations. Empty workspaces and custom profiles survive restarts. No model can bypass approval, and a failed request holds no new capacity. Built by ContextSense, with disclosed AI coding assistance.
